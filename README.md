# Dart Lab2 — ToDo приложение

Консольное ToDo-приложение на Dart для лабораторной работы №2.
Программа работает с задачами: добавляет, показывает, отмечает выполненными и удаляет их.

## Запуск

1. Клонировать репозиторий: git clone https://github.com/ALISAkonovalova/Dart_Lab2.git

2. Перейти в папку: cd Dart_Lab2

3. Установить зависимости: dart pub get

4. Запустить: dart run

## Команды

- add — добавить задачу
- list — показать все задачи
- done— отметить задачу выполненной
- delete— удалить задачу
- exit — выйти

## Что изучила

- Создавать классы, поля и конструкторы
- Использовать именованные параметры в конструкторе {required this.title}
- Переопределять метод toString() через @override
- Делать геттеры (String get status => ...) — вычисляемые свойства
- Работать со static полями и приватностью через _
- Подключать внешние пакеты из pub.dev (ansicolor) и настраивать цветной вывод в терминале

## Ответы на вопросы

1. Поле класса принадлежит объекту и живёт всё время, пока существует объект.
Обычная переменная в функции существует только во время выполнения этой функции
и уничтожается при выходе из неё.
2. Конструктор — специальный метод, который вызывается при создании объекта через
Todo(...). Он нужен, чтобы задать начальные значения полей.
3. `@override` — аннотация, которая говорит компилятору: «этот метод переопределяет
метод родителя». Она защищает от опечаток: если написать `toStrng()` вместо
`toString()`, компилятор сразу ругнётся.
4. Обычное поле — у каждого объекта своя копия. Статическое — одно на весь класс,
существует в единственном экземпляре.
5. В Dart `_` в начале имени делает идентификатор **приватным для файла**.
